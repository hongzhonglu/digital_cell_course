# 模块02：GEMs 构建与表型预测

**对应课次：课程 4《GEMs 构建与表型预测》**

## 模块目标
1. 用 `cobra.Model / Reaction / Metabolite` 从零手工构建一个最小糖酵解 toy 模型，理解 GEM 三要素（代谢物、反应、边界条件）与目标函数设定。
2. 以 e_coli_core 为例预测不同碳源下的最大生长速率，并做葡萄糖摄取速率扫描（简化版表型相平面 PhPP / 鲁棒性分析）。
3. 用 `single_gene_deletion` 做全模型单基因敲除，预测必需基因。

## 代码规范说明（第二轮完善）
- 变量名/函数名为英文 snake_case；print 输出与函数 docstring 为英文；解释性注释保持中文；每个脚本开头有中文块注释说明目的与用法；图表文字为英文。
- 每个脚本均可独立 `python xxx.py` 运行，关键中间结果均有 print。

## 依赖安装
```bash
pip install cobra pandas matplotlib
```

## 文件清单与运行顺序
| 顺序 | 文件 | 内容 |
|---|---|---|
| 1 | `01_从零构建toy模型.py` | 手工构建糖酵解 toy 模型：代谢物（含 formula）+ 反应 + 交换/生物量反应，并演示 GPR（`gene_reaction_rule`）与 subsystem 写法、`model.medium`、`model.summary()`，最后 FBA 求解 |
| 2 | `02_表型预测_生长速率.py` | 7 种碳源生长预测 + 葡萄糖摄取扫描（有氧/无氧），输出 CSV 和 PNG |
| 3 | `03_单基因敲除与必需基因预测.py` | 单基因敲除、必需基因统计，输出 CSV 和直方图 PNG |
| — | `model_loader.py` | 模型加载辅助：优先在线 `load_model("e_coli_core")`，离线自动回退本地缓存 |
| — | `e_coli_core.xml.gz` | e_coli_core 模型本地缓存（BiGG 官方文件） |

运行方式：
```bash
python 01_从零构建toy模型.py
python 02_表型预测_生长速率.py
python 03_单基因敲除与必需基因预测.py
```

## 预期输出（关键数字）
- **脚本1**：toy 模型 9 反应 / 8 代谢物（设置了 5 个演示用 GPR 基因）；葡萄糖摄取上限 10 时生物量通量 **2.9**，改为 5 后降为 **1.4**。
- **脚本2**：碳源生长速率：葡萄糖=果糖 **0.8739** > 琥珀酸 0.3976 > 富马酸 0.3707 > 乳酸 0.3503 > 丙酮酸 0.2912 > 乙酸 0.1733 (1/h)；摄取速率 12 时有氧生长 **1.057**、无氧仅 **0.273** (1/h)。
  - 输出：`output/不同碳源生长速率.csv`（英文列名）、`output/葡萄糖摄取扫描_表型相平面.csv`、`output/表型相平面_葡萄糖摄取扫描.png`。
- **脚本3**：137 个基因中预测出 **7 个必需基因**（占比 5.1%，如 b1136/b1779/b2415/b2416/b2779/b2926/b0720），22 个“部分必需”基因（相对生长 1%~50%）。
  - 输出：`output/单基因敲除结果.csv`（英文列名）、`output/单基因敲除_生长分布直方图.png`。

## 说明
- 必需基因判定阈值：敲除后生长 < 野生型的 1%。
- e_coli_core 为核心模型，不含甘油交换反应；换用 iJO1366 等全基因组模型可扩展更多碳源。
- 课堂若无法联网，`model_loader.py` 自动使用本地 `e_coli_core.xml.gz`，结果一致。
